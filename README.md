# Repo Hunter

Repo Hunter of Fvt Domain

A simple Bash utility that helps you discover popular GitHub repositories based on a topic or keyword. It searches GitHub's public repository API, filters results by stars, and saves matching repository URLs to a text file.

## What it does

- Prompts the user for a topic or keyword
- Normalizes the input for GitHub search queries
- Searches GitHub repositories with a minimum star threshold
- Retrieves the top matching repositories
- Saves the results to a file named using the chosen topic
- Prints the total number of repositories found

## Example

```bash
./repo-hunter.sh
```

When prompted:

```text
What topic are you interested in?
```

Enter something like:

```text
machine learning
```

The script will search GitHub for repositories related to that topic and save results to a file such as:

```text
machine+learning-repos.txt
```

## Requirements

- Bash
- curl
- jq

Install dependencies if needed:

```bash
# macOS (Homebrew)
brew install jq

# Ubuntu/Debian
sudo apt-get install jq curl
```

## Usage

1. Make the script executable:

```bash
chmod +x repo-hunter.sh
```

2. Run it:

```bash
./repo-hunter.sh
```

3. Enter a topic or keyword when prompted.

4. Review the saved repository list in the generated text file.

## Output format

The script stores repository URLs in a file with this pattern:

```text
<topic>-repos.txt
```

Each line contains a GitHub repository URL, for example:

```text
https://github.com/microsoft/vscode
https://github.com/nodejs/node
```

## Notes

- The script searches repositories with `stars:>50`.
- It uses GitHub's public search API.
- Results are limited by the API response and pagination logic used in the script.
- Internet access is required to query GitHub.
